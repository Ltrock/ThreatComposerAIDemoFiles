# Banking App Terraform Demo

This is a small AWS banking application infrastructure codebase for threat modeling demos.

## Services
- Amazon API Gateway HTTP API
- AWS Lambda
- Amazon RDS PostgreSQL
- Amazon Cognito User Pool
- AWS KMS
- Amazon CloudWatch Logs
- IAM roles and policies
- Security groups

## Purpose
This project is intentionally simplified and includes a few security gaps so AI-assisted threat modeling tools can identify risks and recommend mitigations.
